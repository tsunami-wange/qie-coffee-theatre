# Qie.Coffee｜喫咖啡 · 海派咖啡剧场

约 14 × 12 m 的建筑外轮廓、约 150 m² 的概念使用面积、层高约 4.6 m 的**课程概念设计**。这是可交互的三维品牌空间展示，不是施工图或真实门店测绘。几何、陈设与品牌内容为 Qie.Coffee 独立设计；所附照片只用于提炼海派建筑语言和材质氛围。

## 启动

需要 Node.js 20+ 和 pnpm。

```bash
pnpm install --ignore-scripts
pnpm dev
```

打开 `http://127.0.0.1:4173/`。当前开发服务器在启动时构建一次；修改源码后重新运行 `pnpm dev`。也可以在一般开发环境中使用 Vite：`pnpm exec vite --host 127.0.0.1`。标准静态构建采用 esbuild，以兼容当前 macOS 环境的 Rollup 原生模块签名限制。

```bash
pnpm build
pnpm preview
```

产物在 `dist/`，同时复制到可直接用于 GitHub Pages 的 `docs/`。资源路径相对于页面，可部署在仓库子目录。项目不需要后端、账号或收费 API。

## 操作

- 左侧选择区域；“推门进入”打开双门并移动镜头。
- 鼠标拖动旋转视角，滚轮缩放；俯瞰会隐藏屋顶。
- “漫游”模式用 WASD / 方向键移动，拖动鼠标转向。空间边界和舞台有基础碰撞约束。
- 右侧 **Z 纵深** 打开镜头纵深滑块：Z 表示店铺前后方向，X 表示左右，Y 表示高度。滑块在旋转观察模式下沿世界 Z 轴移动镜头，并显示实时坐标；切换导览区域会重置滑块。
- 顶栏自动导览每 6.5 秒切换一个区域，按钮可暂停；手动选择区域也会退出自动导览。
- 右侧切换昼夜、互动提示点、小地图和全屏。手机可触控旋转与缩放，并用区域导航。
- 点击门、幕布、咖啡机、产品、食材、座位、留声机、文化卡及礼品可查看说明。点击食材可加入本地概念配方。
- Qie.Lab 的三张产品海报分别打开蝴蝶酥、酒酿圆子和上海八宝咖啡详情；Qie.Mix 的桂花陈列图可加入配方；文创商店的礼盒画框可查看并切换两张礼盒概念图。入口的“本月风味演出”也展示酒酿圆子海报。
- 没有设置点单网址时，“进入点单系统”打开本地简化 DIY 面板，不会提交真实订单。

## 如何调整

| 内容 | 文件 | 方法 |
| --- | --- | --- |
| 品牌与点单地址 | `src/config.ts` | 修改 `siteConfig.brand` / `orderingUrl` |
| 空间尺寸与色彩 | `src/config.ts` | 修改 `dimensions` 与 `palette`；改变尺寸后同步调整几何坐标 |
| 导览镜头 | `src/config.ts` | 修改 `areas` 中的 `position` 与 `target` |
| 产品、配料与文化说明 | `src/config.ts` | 修改 `products`、`ingredients`、`content` 的中英文字段 |
| 产品海报与礼盒图片 | `public/images/`、`src/config.ts` | 将图片放在 `public/images/`，并在对应条目的 `images` 数组中引用 `./images/文件名` |
| 建筑、家具、区域模型 | `src/Scene.tsx` | 调整 `Facade`、`Walls`、`Seating`、`Stage`、`Lab`、`Mix` 等组件 |
| 界面和移动布局 | `src/main.tsx`、`src/styles.css` | 修改控制逻辑与样式 |

模型使用 Three.js 原生几何与程序化组合，无外部 GLB 或远程贴图依赖。`src/textures.ts` 用 Canvas 在本地生成红木纹理和复古小块马赛克；`src/Refinements.tsx` 包含吧台、咖啡机、杯具、菜单与桌面细节。用户提供的六张品牌概念图经压缩后保存在 `public/images/`，构建时复制到 `dist/images/` 和 `docs/images/`，用于三维展陈画框和点击后的详情卡。`Label` 使用浏览器 Canvas 生成文字贴图。新增热点时，给三维物体绑定 `onClick`，并将对应内容加入 `content`。

## 接入已有点单网站

`src/config.ts` 的 `siteConfig.orderingUrl` 已设置为 `https://tsunami-wange.github.io/qie-coffee/`。顶栏点单入口和 DIY 按钮会在新标签页打开该站点。现有点单站不在本项目中，也没有被复制或改写。

## GitHub Pages 手动部署

1. 运行 `pnpm build`，提交更新后的 `docs/`。
2. 在仓库 **Settings → Pages** 中选择主分支和 `/docs` 目录。
3. 等待 Pages 给出站点网址。网站使用相对路径，可适应仓库子路径。私有仓库能否启用 Pages 取决于 GitHub 账户方案。

当前项目没有配置自动发布工作流；Pages 使用分支中的静态 `docs/` 文件。

## 已知边界

移动碰撞覆盖建筑边界、门洞、舞台、主要展柜及桌位，不是完整物理引擎。音频资源尚未提供，声音按钮为预留接口，页面不会自动播放。产品与售价为课堂展示的概念内容，不代表真实售卖。文化展陈明确区分通用历史背景与品牌创意构想。


## 前台咖啡与材质细节

`src/CoffeeDisplay.tsx` 根据提供的海报制作酒酿圆子、蝴蝶酥和八宝咖啡三款程序化立体杯：包含分层奶咖、杯沿、奶油旋纹、圆子或酥片、托盘与海报立牌。点击杯子或立牌打开对应产品详情。这些是按图片重建的概念模型。该文件也提供本地环境反射，无需远程 HDR 文件。

光照包含日光、半球补光、暖色吧台聚光和壁灯；金属使用环境反射，木饰面使用细微凹凸与清漆，吧台使用程序化深色石纹。砖墙有实体灰缝底层。阴影使用 2048 日光贴图与 1024 吧台贴图。


## 沙发、甜点与视角高度

座位区使用配套墨绿皮质沙发，包含软包坐垫、拉扣靠背、滚边、铜钉与金属脚套。下午茶桌与吧台增加带酥皮分层、卷纹和糖粒的蝴蝶酥，以及带沟槽与焦糖表面的可露丽；杯顶蝴蝶酥复用同一精细模型。

先点击三维画面，按住 **空格** 抬高视角，按住 **Shift** 降低视角；松开后停在当前高度。旋转观察与自由漫游均支持此操作。室内高度限制为 0.75–4.1 m，门外上限为 12 m，俯瞰上限为 28 m。输入框、按钮与弹窗操作不触发升降；窗口失焦时停止移动。切换导览区域或模式会回到对应的初始高度。沙发也加入平面漫游碰撞范围。


## 手机漫游

手机上选择“漫游”后，左下摇杆控制前后与横移，右侧空白画面拖动调整视角。右下按钮按住升高或降低视角，松开即停止。进入漫游会收起导览、地图和纵深面板；在门外选择漫游时自动进入店内。点击“退出漫游”回到旋转观察。桌面键盘操作仍可使用。


手机工具栏默认只显示“漫游、旋转、重置”三个按钮。点击“旋转”展开全部工具，再点一次收起；点击“漫游”进入移动摇杆界面。展开的九项工具以三列排布，避免一整排横跨手机屏幕。
